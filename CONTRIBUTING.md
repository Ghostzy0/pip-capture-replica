# Contributing

Use a focused branch and pull request. Describe a reproducible problem, changed behaviour, checks and limits. Run `swift test --jobs 2` and `./scripts/build.sh`; for baseline changes also run its tests and build script. Use synthetic fixtures, never personal recordings. Do not commit weights, builds, credentials, raw competitor captures or reserved brand/motion code. Keep each edition's provenance and notices. Native microphone/focus/assistive behaviour needs actual macOS evidence; source tests alone are insufficient.
