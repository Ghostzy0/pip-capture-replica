# Security and privacy

Pip Capture is an experimental local app. Its data is plaintext in your OS account's Application Support directory; protect and back it up accordingly. No telemetry, mandatory account, automatic model downloads or remote transcription is implemented. The configured speech executable is code running with your user rights; choose only a trusted reviewed build. Models and third-party runtimes have their own licences.

Use a private GitHub security advisory on this repository when available. If that is unavailable, open a minimal issue asking for a private channel; do not publish recordings, credentials or exploit details. No response-time guarantee is promised. Ad-hoc signatures establish package integrity locally, not a verified publisher or notarisation.

The separately declared baseline preserves optional upstream backend source, which has broader setup/dependency behaviour and is not the Pip privacy contract. No optional backend setup is run by either build script. Treat it as experimental comparison source; see UPSTREAM.md.
